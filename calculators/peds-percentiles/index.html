    Примечание

    Калькулятор объединяет расчёт педиатрических процентилей по стандартам ВОЗ (метод LMS): вес, рост, ИМТ, окружность головы, масса при рождении и масса плода.

    Потенциал роста ребенка на основании роста родителей рассчитывается по среднему росту родителей: для мальчиков (рост отца + рост матери + 13) / 2, для девочек (рост отца + рост матери − 13) / 2; диапазон ±8,5 см.

    Масса плода — формула Hadlock по параметрам УЗИ (AC, FL, HC, BPD); процентиль — по кривым ВОЗ.

    Процентиль показывает долю детей того же пола и возраста с меньшим значением показателя. Оценка проводится в динамике; резкий переход через 2+ «канала» процентилей требует консультации педиатра.
