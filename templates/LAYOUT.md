# Каркас калькулятора на сайте

На [farmconsilium.com/calculator](https://farmconsilium.com/calculator) меняется только **содержимое** калькулятора; **зоны на странице** у всех одинаковые.

## Порядок зон (не менять)

| # | Класс | Что внутри |
|---|--------|------------|
| 1 | `fc-calc__head` | Заголовок + описание |
| 2 | `fc-calc__body` | Форма: поля, чекбоксы шкалы |
| 3 | `fc-calc__actions` | Кнопка «Рассчитать» (`form=""` на кнопке) |
| 4 | `fc-calc__result-wrap` | Блок результата (всегда на экране, `min-height`) |
| 5 | `fc-calc__foot` | Дисклеймер + источник |

Обёртка: `fc-calc__layout` внутри `fc-calc__card`.

## Что можно менять в новом калькуляторе

- Текст в `fc-calc__head`
- Разметка внутри `fc-calc__body`
- Логика `calculate()` в `<script>`
- Текст в `fc-calc__source`

## Что нельзя

- Убирать или переставлять зоны 1–5
- Прячать `fc-calc__result-wrap` через `hidden` / `display:none`
- Кнопку переносить внутрь `body` без `fc-calc__actions`
- Добавлять вторую кнопку «Рассчитать» в другом месте

## Результат

Использовать `showResult()` / `clearResult()` из шаблона — класс `fc-calc__result--empty`, не `hidden` на обёртке.
